# 📘 Chapter 08: Complete Shortcuts & Drag-and-Drop Cheatsheet 📑⚡

> **Sabhi scrcpy keyboard shortcuts, mouse actions aur drag-drop gestures ka master reference.**

---

## ⌨️ Live Window Keyboard Shortcuts

| Shortcut | Kaam |
| :--- | :--- |
| **`Alt + r`** | Screen ya Camera ko **90° Rotate** karna (Vertical ↔ Horizontal) |
| **`Alt + f`** | **Fullscreen Mode** toggle karna |
| **`Alt + h`** | **Home Screen** par jana |
| **`Alt + b`** | **Back Button** dabana |
| **`Alt + s`** | **Recent Apps (App Switcher)** kholna |
| **`Alt + o`** | Phone ki **Physical Display OFF** karna (PC par chalta rahega) |
| **`Alt + p`** | Phone ki **Physical Display wapas ON** karna |
| **`Alt + n`** | **Notification Panel** neeche girana |
| **`Alt + Shift + n`** | **Quick Settings Panel** kholna |
| **`Alt + v`** | PC ka clipboard phone me **Paste** karna |
| **`Alt + c`** | Phone ka text PC clipboard me **Copy** karna |
| **`Alt + Up / Down`** | Phone ka **Volume Up / Down** karna |
| **`Alt + w`** | Screen par **Zoom** reset karna |
| **`Ctrl + C`** | scrcpy process ko **Exit / Close** karna |

---

## 🖱️ Mouse Actions

| Mouse Action | Phone me Action |
| :--- | :--- |
| **Left Click & Drag** | Touch, Tap & Swipe |
| **Right Click** | ⬅️ Back Button |
| **Middle Click (Scroll Click)** | 🏠 Home Screen |
| **Mouse Wheel Scroll** | Smooth Vertical Scrolling |
| **Double Click Black Border** | Window resize / Auto-fit |

---

## 📂 Drag-and-Drop Superpowers

| Drag Action | Result |
| :--- | :--- |
| **`.apk` file drag karke drop karna** | App phone me **direct install** ho jayegi! |
| **Photo / Video / Document drag karna** | File phone ke `/sdcard/Download/` me push ho jayegi. |
