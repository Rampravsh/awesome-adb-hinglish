# 🤝 Contributing to Awesome ADB in Hinglish

Is open-source project me contribute karne ke liye aapka swagat hai! 🎉

Agar aapke paas koi nayi **ADB command, script, ya trick** hai jo baaki Indian developers ke kaam aa sakti hai, toh aap asani se contribute kar sakte hain.

---

## 🛠️ Kaise Contribute Karein?

1. **Fork karein**: Top right me **Fork** button par click karein.
2. **Clone karein**:
   ```bash
   git clone https://github.com/YOUR-USERNAME/awesome-adb-hinglish.git
   ```
3. **Branch banayein**:
   ```bash
   git checkout -b add-my-awesome-command
   ```
4. **Changes karein**:
   - Nayi command ko `README.md`, `CHEATSHEET.md` ya kisi module me add karein.
   - Bhasha **aasan Hinglish** me honi chahiye.
   - Example aur use-case zaroor shamil karein.
5. **Commit & Push**:
   ```bash
   git commit -m "feat: added new wifi adb command"
   git push origin add-my-awesome-command
   ```
6. **Pull Request (PR) create karein!**
